# 禅阅

禅阅提供独立 iOS App 工程和网页版 PWA，使用 React、TypeScript、Vite、Capacitor 和 PDF.js。无需后端，书籍解析在本机完成。

## 安装独立 iPhone App

`ios/App/App.xcodeproj` 是真实 iOS 原生工程，不是 Safari 主屏幕书签。界面、PDF 引擎/工作线程/字库、示例书都内置在安装包，首次启动也无需网络。运行时不需要电脑、HTTP 服务或预先缓存。

### Windows 免费方案：GitHub 公开仓库云编译 + 本机免费签名

无需购买 Mac 或 Apple Developer Program。**免费签名通常只有 7 天有效期，需要定期联网刷新；并非一次安装后永久离线可用。** 运行期间无需电脑保持开机。源码托管在 [wmjjhs/chanyue](https://github.com/wmjjhs/chanyue)。每次升级必须下载对应提交的新构建产物，旧 IPA 不包含后续改动；云构建成功不代表完成签名、安装或真机流畅度验收。

#### 2. 手动构建和下载安装包

1. 确保工作流文件已在仓库默认分支。打开仓库的 **Actions → 禅阅 · 免费构建 iPhone 安装包 → Run workflow**。

4. 在本次运行页面的 **Artifacts** 下载 `chanyue-unsigned-iphone`，解压下载的外层 ZIP，得到 `Chanyue-unsigned.ipa`。**不要再解压 IPA，也不能点击 IPA 直接安装。** 产物仅保留 3 天，请保存到自己的电脑。
5. 如果任务失败，查看首个失败步骤；编译日志会尝试保存为 `chanyue-ios-build-log`。提供错误片段即可排查，不要提供账户密码。日志产物用于诊断，不代表已经构建成功。

#### 3. Windows 免费签名安装

1. 按 [AltStore Classic 官方 Windows 安装指南](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows) 安装 AltServer；根据该指南准备 Apple 官方版本的 iTunes/iCloud，不购买收费签名服务。请核实下载源，不运行来历不明的修改版安装器。
2. 用数据线连接 iPhone、解锁并信任自己的电脑，按指南开启 Wi-Fi 同步。通过 AltServer 的 **Install AltStore** 安装 AltStore Classic。
3. 在你自己的可信工具窗口输入免费 Apple ID，按手机提示信任开发者；iOS 16+ 通常还需启用开发者模式。**Apple ID 密码只由你在本机输入，不发给助手或 GitHub。**
4. 将对应新版 `Chanyue-unsigned.ipa` 保存到 iPhone 的「文件」中。打开 AltStore Classic → **My Apps → +** 选择 IPA，并保持手机能连接正在运行的 AltServer，完成签名和安装。覆盖升级须使用原来的 Apple ID，并保持 Bundle ID `app.chanyue.reader` 不变；不要先卸载旧版，避免丢失书库。若当前版本界面不同，以官方说明为准。
5. 安装成功后先完成系统要求的联网信任/验证，再开启飞行模式打开禅阅。阅读引擎、中文 PDF 字库和示例书均在包内。尚未下载的 iCloud 书籍需要先保存到本机。

工作流配置位于 `.github/workflows/ios-unsigned.yml`，打包脚本位于 `scripts/build_unsigned_ios.py`。云构建只生成未签名产物；只有完成本机签名、安装并在 iPhone 验收后，才能确认实际安装可用。

### 在 Mac 上编译和安装（可选）

1. 准备能运行 **Xcode 26.0+** 的 Mac、Node.js 24、Apple ID 和 iPhone。Capacitor 8 的最低系统配置为 iOS 15；实际兼容性仍需在目标系统真机验收，建议使用较新的 iOS。
2. 将**整个项目**复制到 Mac（保留 `ios`、源码和 `public`，无需复制 Windows 的 `node_modules`），在项目根目录执行 `npm ci`。
3. 执行 `npm run ios:sync`：构建 `dist-native`、验证离线资源、同步插件和本地资源到 `ios/App/App/public`。不要重新运行 `cap add ios`，工程已存在。
4. 执行 `npm run ios:open`，或用 Xcode 打开 `ios/App/App.xcodeproj`。SPM 会在构建时下载依赖；**这是开发构建需要网络，不是 App 运行需要网络**。
5. 在 Xcode 的 App target → Signing & Capabilities 勾选 Automatically manage signing，选择自己的 Team。默认 Bundle ID 是 `app.chanyue.reader`；如与签名账户冲突，改成你自己的唯一标识，并同步更新 `capacitor.config.ts`。不要把 Apple 密码或证书私钥写入项目。
6. 连接 iPhone、信任 Mac，按系统提示启用开发者模式，选择该设备后点击 Run。安装完成后即可断开电脑，打开飞行模式独立使用。

**Windows 不能运行 Xcode 编译 iOS 原生代码，但可通过 AltServer 等工具给云端编译出的 IPA 进行本机侧载签名。当前提供工程和云构建配置，不等于已经生成已签名 `.ipa`，也不代表已通过 App Store 审核。** 免费 Personal Team 安装通常需要定期重新签名，不能保证永久使用；TestFlight 安装也有有效期。正式长期分发请使用 Apple Developer Program 和适合的分发渠道。构建/签名/首次分发可能联网，阅读功能不联网。

### 原生存储与导入

- 正文放在 App 的 `Library/Chanyue/books` 私有文件夹，不是 WebView 缓存；设置和阅读进度使用 iOS UserDefaults（Preferences 插件）。
- App 不主动上传或跨设备同步；是否参与系统/iCloud 备份由用户的 iPhone 备份设置决定。卸载 App 会删除本机数据，请保留原始文件。
- 从「导入 → 文件 → 我的 iPhone」选择 TXT、DOCX、文字型 PDF。未下载的 iCloud 文件仍需联网下载，离线导入请提前存到手机上。
- 网页版与独立 App 的存储隔离，原有网页书架不会自动迁移，需要重新导入。
- 工程包含中文名称、横竖屏配置、禅阅 App 图标和 `PrivacyInfo.xcprivacy`（文件时间戳及 UserDefaults 理由声明）。
- 原生资源与 PWA 分开构建；发布配置没有 `server.url`，原生页面禁用 Service Worker，并通过 CSP 限制外部资源。

### 真机离线验收

安装后**首次启动前**开启飞行模式：打开 App → 导入三种本地文件 → 设置最高速度 1600 → 横竖屏阅读 → 锁屏/切后台 → 重开确认进度和设置 → 删除/重命名。还需检查设备字体、文件选择器、刘海安全区、iOS 隐私清单与签名；Windows 下的 WebKit 模拟不能替代这些验收。

## 启动网页版

推荐 Node.js 24。首次运行 `npm install`，然后运行 `npm run dev`，打开终端显示的网址（默认 `http://localhost:5173`）。

`npm run build` 生成 `dist`；`npm run preview` 预览生产版本（默认端口 4173）。将 `dist` 部署到 HTTPS 网站根目录，即可在 iPhone Safari 中通过「分享 → 添加到主屏幕」使用。

手机与电脑连接相同 Wi-Fi 后，可用电脑的局域网 IP 和开发端口测试，例如 `http://电脑局域网IP:5173`。手机上的 localhost 不指向电脑；防火墙需允许开发端口。局域网 HTTP 开发访问不支持离线安装，完整 PWA 体验需要 HTTPS。

## 功能

- 多行连续引导阅读：正文不横向移动，下划线始终在文字下方；换行直接从下一行字下开始，没有跨行飞行或斜线连接。默认「指读」模式，像笔尖一样向前移动、经过不留痕；可切换「划线留痕」，从行首逐渐画到已读位置，已读行保留线条。保留文档字号与加粗层级，指读经过时不额外放大、不变色。默认 240 字/分钟，不自动播放。
- 阅读主屏顶部仅保留一行返回、书名和设置；底部播放及前后翻页按钮成组居中，页码、跳转输入和阅读百分比合为一行。点击顶部书名才展开「目录／搜索／书签·摘录」，不增加常驻工具栏；定位后按需出现「返回刚才」入口。保留系统安全区；阅读区铺满标题与按钮之间的可用高度，上下间距一致（竖屏4px、窄横屏2px），文字行距随高度均匀分配，不再在阅读区下方保留大块空白。
- 目录读取Word标题／大纲级别和PDF内置书签，不按字号猜章节；PDF定位至目标页可提取正文的开头，外部链接不作为目录跳转。目录标明当前章节，长目录打开时自动显示该处。正文搜索支持关键词或短句、忽略英文大小写，最多输入100个字符、显示前200条匹配，不执行用户正则。中文输入法选字结束后再查找；回车可立即搜索，但不自动跳转或改变阅读进度。同一次阅读内保留工具分类、关键词与上次查看的匹配，返回书架或刷新页面后清除，不写入搜索历史。长列表在面板内滚动，关闭及分类入口保持可见。打开工具先暂停，定位后仍暂停，可返回本次首次跳转前的源位置。
- 书签记住当前位置；摘录默认当前句，也可保存搜索匹配文字，默认只展示摘录与备注，展开「调整摘录范围」时预选当前摘录，可在附近原文框重新选取文字；窗口包含完整的2000字符允许范围，连续调整时坐标不变，原样应用不会制造未保存修改。笔记列表预览最多三行原文、两行备注，编辑时仍显示完整内容，不裁剪已保存数据。每书最多200条，单条摘录2000、备注500个UTF-16码元（部分字符占两个）；修改字号、重命名、保存进度或同正文重导入不覆盖笔记。写入失败保留草稿，多窗口过期修改／删除会提示冲突，不覆盖新内容；关闭未保存编辑需确认。
- 三种离线排版：语义段落保留原始段落、首行缩进、英文词间隔，并尽量避免标点出现在行首；紧凑排列保留标点、去掉段落空白；无标点密排再去掉标点，连续排满。只改变显示，不改写原文，不使用联网 AI。
- 设置宋体／黑体／楷体、12–64 px 字号、文字颜色、阅读区域背景、页面背景、最多2–30行、下划线停留行第2–30行、指读／划线留痕两种模式、下划线颜色或透明、指读1–50字窗口、1–6px线条粗细及30–1600字/分钟。透明时隐藏下划线；关闭透明后恢复原颜色。线宽切换不改变文字尺寸、行距或页数。按 Unicode 非标点字素计数（含数字、字母、emoji等）；标点与空白不计时，窗口覆盖字数也不计标点。组合emoji不拆开（旧内核回退到码点）。
- 下划线与字形之间预留间距，最粗线条也不会遮挡文字；指读时本行不足窗口字数就覆盖全行，不同时跨两行覆盖；留痕模式不受窗口长度限制，已画线条从各行行首保留到当前位置，切回指读恢复原窗口长度。字号过大可调小以容纳更多字。屏幕不足时实际显示行数小于设置上限，极大字号会临时缩小以容纳至少两行两列，原设置不变。
- 下划线停留行从上往下计数，默认第2行，可调至第30行。每行从所选行位置开始，随正文在附近平滑上移，并非固定屏幕像素；保留前一行空间以免顶部裁字。所选行超出实际可显示行数时临时使用最后可见行，恢复空间后回到原偏好，不改源阅读进度、字速或页数。指读与留痕均生效，缓冲区随停留位置移动以显示前文。
- 正文上移与下划线共用一个动画时钟。正文用单调三次曲线连接各行位置，长短行边界保持位置和速度连续；同字数满行时匀速上移。行内指读持续向前，留痕笔尖沿纯文字时钟推进；等宽无标点行匀速，含标点或词间距时平滑调整像素速度，不额外停顿。换行直接进入下一行，不增加飞行时间。正文采用有界行缓冲与节点复用，避免逐字重建正文。
- 支持开始／停止、后退一页、前进一页、输入页码跳转、读完停止及重读。每页按当前实际可显示行数统计，总页数为总排版行数除以每页行数后向上取整；末页不足仍计一页。翻页落在目标页首并暂停，左右键翻页；输入页码时暂停阅读，禁止越界或小数页码。纯标点页仍可手动浏览，但不额外计时；空正文无页可跳转。
- 暂停时文字和光标同时停止；后台暂停保存，设置窗口暂停。字号/行数/窗口/模式/方向变化保持源字符锚点及小数进度，按新排版重新统计页数，不固定旧页码；光标的具体屏幕位置随新排版重新计算。仅含标点或空白时不自动阅读。
- 留痕由当前源阅读进度重建：暂停保留，重启续读恢复；字号、排版和方向变化后按新位置绘制。切回指读隐藏留痕，后退或跳页按新进度重建，重新阅读从零开始，不使用历史最大进度。原文不修改，也不把留痕另存为永久批注；每个缓冲行仅一个线条节点，长书不会累积整本DOM。
- 留痕层次可配置：当前线、刚读完线、最淡不透明度（0–100%，依次不增）、渐淡跨度（1–30行）、过渡时长（0–1秒），附层次预览及恢复默认。默认100%／65%／25%、5行、0.4秒；从上一行向前经过指定跨度达到最淡。仅作用于划线留痕，关闭渐淡恢复同深，透明开关优先；过渡跟随阅读时钟，暂停冻结，续读重建，不改变字速。
- 离线环境音提供柔雨、微风、流水，单选不混音。默认关闭，音量默认20%，独立调节0–100%；开始阅读手势后才播放，音量变化与启停使用约350毫秒过渡。阅读暂停时默认继续，可关闭此选项；设置、翻页与读完暂停遵循同一偏好。返回书架停止，锁屏或进入后台立即停止，回前台不会自动出声，不提供后台播放器。
- 环境音为已试听确认的真实录音：雨B「轻柔雨幕」— [soundrecorder7 / 167034](https://freesound.org/people/soundrecorder7/sounds/167034/)，风A「风过树叶」— [o_ciz / 475448](https://freesound.org/people/o_ciz/sounds/475448/)，溪A「苏格兰浅溪」— [BurghRecords / 446019](https://freesound.org/people/BurghRecords/sounds/446019/)，原站均标注 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。使用与试听同源、哈希核验的公开高质量MP3预览，非原始无损录音；解码后保持双声道（雨B左右相同，不人工扩宽），只做恒定增益、去直流及2秒平滑等功率首尾交叠，不加音乐。正式循环为24／58／58秒，44.1kHz、16bit PCM WAV，总计约24.7 MB。
- `assets/ambience/` 保存处理后的gzip无损压缩资产及 `sources.json` 来源、授权、选音、参数和哈希清单；`scripts/generate-ambience.mjs` 常规构建仅使用Node内置模块解压核验，无需联网、Python或FFmpeg。重新处理需 `numpy`、`imageio-ffmpeg`，运行 `python scripts/prepare-recorded-ambience.py --source-directory <含manifest.json与original-previews的已核验试听目录>`。PWA缓存单文件上限11 MB、运行时读取上限11 MB，时长上限仍60秒。错误或中断不阻断阅读；请配合系统音量低音量使用，百分比不代表安全响度。最终循环听感及真机表现仍需iPhone验收。
- 手机横竖屏布局自动切换。需关闭 iPhone 的竖排方向锁定；App 不会强行锁定方向。动态文字仍可能引发不适，建议先用120–300字/分钟，出现不适立即暂停，不能保证消除头晕。
- 书架支持批量导入、搜索、排序、阅读状态筛选、重命名和确认删除。
- 网页版使用 IndexedDB 与 localStorage；独立 iOS 版使用私有文件夹与 Preferences。内容仅以纯文本渲染。
- 独立 iOS 版资源随包安装、首次启动无需联网；PWA 则需先联网完成缓存。开发模式不注册 Service Worker。
- 包含三篇原创示例短文，可删除；删除全部书籍后不会重复生成示例。

## 支持格式与边界

- **TXT**：UTF-8、GB18030、带 BOM 的 UTF-16 LE/BE。
- **Word**：`.docx` 正文、表格文字保留加粗及相对字号，包括文档默认字号、段落/字符样式继承、标题层级、直接格式及显式取消加粗；不复刻原页版式，不保留图片、字体家族、颜色等。本次仅支持常见正文样式，不处理表格条件样式或主题字体映射。旧二进制 `.doc` 需另存为 `.docx`，加密文档不支持。
- **PDF**：可提取文字的 PDF，包括常见中文编码。按文字变换提取相对字号，等待字体元数据后尽量保留可识别的粗体；隐藏字体名、自绘描边粗体或图片文字无法保证识别，不推测重点。扫描件先 OCR，加密件需先解除保护，复杂分栏按提取顺序。
- 字号以正文常用大小为基准，保留0.7–2倍层级，全局字号设置整体缩放；极端字号有安全限幅。为保持滚动稳定，同书行高按最大字形预留，标题较大时可见行数会减少。字格宽度随字号/粗体变化，换行、指读、留痕和页数使用同一宽度模型，字数时钟和UTF-16源锚点不变。阅读区允许合成粗体，以支持只有常规字重的宋体/楷体。
- 单文件最多 20 MB，正文最多 200 万 UTF-16 码元，PDF 最多 2000 页，每批最多 10 本；Word 解压大小上限 80 MB。
- 新导入保留原始段落，屏幕换行随字号和宽度计算，不修改书籍正文。TXT/PDF 的段落质量取决于源文件换行和提取结果；不会自动推断复杂版面语义。旧版已导入的书籍曾被截断为短阅读行，无法凭空恢复原始段落，建议保留原书并重新导入。
- 旧版书架、配色、透明选项和源进度不清空；旧放大倍率会忽略，下划线默认2px，不再缩放文字；旧设置没有模式选项时默认使用指读，没有停留行时默认第2行，原有行数、粗细和配色保留。更早的像素速度不适用于字/分钟，迁移时默认240字/分钟；已有字速不重置。旧行进度从阅读行起点恢复，之后使用稳定字符位置保存。
- 旧书不会自动恢复已丢失的格式或目录。重新导入原Word/PDF，正文及段落完全一致且新文件带有不同样式或目录时，只更新对应字段，保留ID、重命名、封面、创建时间、完成状态、源阅读进度与独立笔记；格式和目录均无变化时仍提示重复，空字段不会清除已有格式或目录。若旧版曾截断段落或源文件改过文字，无法安全自动对齐，作为新书导入。目录最多1000项，TXT不推测目录。
- 书签与摘录只在当前设备的对应书库保存，网页不同域名或端口也相互独立。网页书库升级到IndexedDB v3新增独立笔记仓库，保留旧正文与进度；原生笔记使用独立代际文件，临时写入核验后提交并保留上一代。删除书籍同时删除相关记录：网页使用同一事务，原生先成功删除正文再清理笔记／进度，清理失败会在重开书库时重试。损坏笔记报错且禁止覆盖，不阻断原书阅读；目前没有笔记导出或跨设备同步。
- App 无账号及应用级跨设备同步/云备份；原生数据可能参与用户启用的 iPhone 系统备份。清除网页数据或卸载 App 会影响对应书库及笔记，请保留原始文件。书籍只保存提取的文字、受限字号/粗体区间及目录，不保存或执行原始HTML；样式字段损坏时退回普通正文，旧书无字段仍可读。
- WebKit 模拟测试不等于 iPhone 真机测试；正式使用前建议在目标 iPhone 上验收安全区、系统字体及主屏幕模式。
